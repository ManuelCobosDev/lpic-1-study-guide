# E2E Tests & Capturas
Pruebas integrales de extremo a extremo con Playwright, auditorías de accesibilidad axe y capturas de pantalla.
Contiene los tests de gates (`fase-N.spec.ts`) y evidencias visuales en `screenshots/fase-N/`.
Prohibido modificar tests para forzar el aprobado de un gate.
Prohibido omitir comprobaciones en tema oscuro o resolución móvil.
