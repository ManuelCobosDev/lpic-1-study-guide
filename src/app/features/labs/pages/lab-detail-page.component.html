🐧 Preparación del entorno: Debian 12 (Bookworm)

Para dominar los objetivos de LPIC-1 se recomienda practicar en un entorno GNU/Linux real, nunca en terminales simuladas que no emulan fielmente el comportamiento del kernel o los flujos estándar.

  1. Descarga: Obtén Debian 12 Netinst (ISO mínima oficial) o una imagen de Vagrant (debian/bookworm64).
  2. Virtualizador: Emplea VirtualBox, UTM (macOS), Proxmox o WSL2 con distro Debian.
  3. Usuario: Crea un usuario estándar no root (ej. lpic) con privilegios sudo.
  4. Paquetes recomendados:
    sudo apt update && sudo apt install -y curl vim git net-tools bsdextrautils

Una vez lista tu terminal Debian 12, copia los comandos de cada misión y ejecútalos observando las redirecciones y códigos de salida.
