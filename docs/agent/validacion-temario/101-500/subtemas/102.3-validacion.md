La lección web consta de 19 diapositivas de alta densidad pedagógica con diagramas interactivos, comparativas estáticas vs compartidas, sonames, /etc/ld.so.conf, ldconfig, LD_LIBRARY_PATH, ldd, objdump, orden de enlace dinámico ld.so, y una guía completa de resolución de problemas. ## 2. Qué falta en la Web respecto al PDF Oficial (4 ítems)
- **[flag]** `ldd -u / --unused` (pág. 105): Opción de ldd para imprimir dependencias directas no utilizadas por el ejecutable analizado.
- **[flag]** `objdump --private-headers` (pág. 107): Forma larga del flag -p de objdump para volcar cabeceras privadas ELF (NEEDED, SONAME).
- **[path]** `/etc/bash.bashrc y ~/.bashrc` (pág. 104): Ubicaciones citadas en el manual para definir la variable LD_LIBRARY_PATH de manera persistente a nivel de sistema o de usuario.
- **[exercise]** `Desglose sistemático de sonames (Ejercicio Guiado 1)` (pág. 106): Tabla del ejercicio 1 que pide desglosar 6 bibliotecas (linux-vdso.so.1, libprocps.so.6, libdl.so.2, libc.so.6, libsystemd.so.0, ld-linux-x86-64.so.2) en nombre, sufijo y versión.

## 3. Qué se ha puesto de más en la Web / Contenido Autor (4 ítems)
- **[command]** `file`: Comando para diagnosticar conflicto de arquitectura ELF (ELFCLASS32 vs ELFCLASS64) en la diapositiva de resolución de problemas.
- **[command]** `readelf`: Utilidad alternativa oficial para inspeccionar secciones dinámicas (readelf -d) contrastada didácticamente con objdump.
- **[concept]** `Las 4 librerías fundamentales de glibc`: Desglose específico de libc, libm (-lm), libpthread (-pthread) y libdl (dlopen) con sus banderas de gcc y claves de examen.
- **[concept]** `Resolución sistemática de 4 errores comunes de librerías`: Guía práctica de troubleshooting para 'not found', olvido de ldconfig, wrong ELF class y permisos denegados.
