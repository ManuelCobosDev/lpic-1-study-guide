## 2. Qué falta en la Web respecto al PDF Oficial (5 ítems)
- **[term]** `Logical Extents (LE)` (pág. 71): El PDF explica que los volúmenes lógicos (LV) se componen de Logical Extents (LE) que mapean directamente a los Physical Extents (PE). La lección web explica en detalle los PE pero no menciona la sigla LE.
- **[term]** `CHS (Cylinder-Head-Sector)` (pág. 68): El PDF cita el direccionamiento CHS al detallar la limitación histórica del cilindro 1024 en BIOS INT 13h. La lección explica el cilindro 1024 pero omite el término CHS.
- **[path]** `/dev/VGNAME/LVNAME` (pág. 71): El PDF expone la convención estándar genérica /dev/VGNAME/LVNAME y /dev/mapper/VGNAME-LVNAME. La web emplea rutas de ejemplo específicas (/dev/vg0/lv_var) sin formalizar la convención general.
- **[path]** `/var/cache` (pág. 69): El manual oficial cita /var/cache como ejemplo de directorio de datos variables. La web cita /var/log, /var/lib/mysql y /var/spool/mail.
- **[path]** `/media/USER/LABEL` (pág. 67): El PDF define la convención estándar FHS /media/USER/LABEL para medios extraíbles. La web ilustra con el ejemplo /media/alumno/PENDRIVE.
