Auditoría comparativa completada para el subtema 101.3 ('Cambiar los niveles de ejecución / objetivos de arranque y apagar o reiniciar el sistema'). ## 2. Qué falta en la Web respecto al PDF Oficial (7 ítems)
- **[path]** `/usr/lib/systemd/` (pág. 45): Elemento de la lista parcial de archivos oficial LPI. La web menciona /lib/systemd/system/ pero omite la ruta estándar /usr/lib/systemd/ de la especificación LPI.
- **[path]** `/etc/shutdown.allow` (pág. 57): Archivo que restringe a qué usuarios se les permite reiniciar la máquina con la combinación Ctrl+Alt+Supr.
- **[flag]** `shutdown -a` (pág. 57): Opción -a para el comando shutdown en la línea ctrlaltdel de /etc/inittab para comprobar /etc/shutdown.allow.
- **[path]** `/etc/systemd/logind.conf` (pág. 54): Archivo de configuración maestro de systemd para acciones de energía y suspensión (suspend, hibernate, cierre de tapa) cuando no se usa acpid.
- **[path]** `/etc/systemd/logind.conf.d/` (pág. 54): Directorio de configuración modular para directivas de logind en systemd.
- **[command]** `/sbin/sulogin` (pág. 50): Comando para login de usuario único en modo rescate SysVinit definido en /etc/inittab (~:S:wait:/sbin/sulogin).
- **[acronym]** `SIGINT` (pág. 56): Señal de interrupción interactiva mencionada en el contexto de control de procesos y eventos de apagado/reinicio.

## 3. Qué se ha puesto de más en la Web / Contenido Autor (4 ítems)
- **[command]** `systemctl daemon-reload`: Comando indispensable añadido para recargar la configuración de systemd tras editar unidades en /etc/systemd/system/.
- **[command]** `systemctl mask / unmask`: Comando para bloqueo total de servicios mediante symlink a /dev/null, de alta recurrencia en el examen LPIC-1.
- **[path]** `/run/nologin`: Ubicación moderna de runtime del archivo de bloqueo de sesiones antes del apagado.
- **[command]** `systemctl is-failed`: Subcomando útil para verificación de unidades caídas.
