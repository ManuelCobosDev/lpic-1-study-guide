## 2. Qué falta en la Web respecto al PDF Oficial (9 ítems)
- **[flag]** `--boot-directory=/mnt/tmp` (pág. 82-83): El PDF destaca 'grub-install --boot-directory=/mnt/tmp /dev/sda' y '--boot-directory=/boot /dev/sda' como método para instalar GRUB apuntando a una partición de arranque alternativa o dedicada montada temporalmente. Es un requisito directo del objetivo oficial de la certificación ('Proporcionar ubicaciones alternativas para el gestor de arranque').
- **[command]** `find (en shell GRUB Legacy)` (pág. 88-89): En la consola interactiva de GRUB Legacy, el comando 'grub> find /boot/grub/stage1' se enseña como el método oficial para localizar en qué disco y partición reside /boot antes de ejecutar 'root (hdX,Y)'.
- **[command]** `search (--set=root, --fs-uuid, --no-floppy, --label)` (pág. 84-85, 96): El PDF enseña que en lugar de 'set root=(hdX,Y)', una entrada de GRUB 2 puede usar 'search --no-floppy --set=root --fs-uuid <UUID>' o '--label <LABEL>' para evitar problemas si cambia el orden de los discos (ejercicio exploratorio 4).
- **[command]** `makeactive` (pág. 91): En la sintaxis de GRUB Legacy para arranque en cadena (chainloading) de Windows, el PDF incluye 'makeactive' para activar la bandera de partición booteable en la tabla MBR.
- **[path]** `/dev/disk/by-uuid/` (pág. 84, 96): El PDF y la respuesta oficial al ejercicio exploratorio 3 prescriben 'ls -la /dev/disk/by-uuid/' para identificar el UUID de una partición. La diapositiva 15 de la web lo sustituyó por 'blkid'.
- **[command]** `fdisk -l /dev/sda` (pág. 82, 96): El manual oficial (pág. 82 y ejercicio exploratorio 2) explica cómo usar 'fdisk -l /dev/sda' para buscar el asterisco (*) en la columna Boot y así determinar cuál es la partición de arranque.
- **[variable]** `GRUB_SAVEDEFAULT= y GRUB_ENABLE_CRYPTODISK=` (pág. 83-84): Variables de /etc/default/grub detalladas en el manual: GRUB_SAVEDEFAULT=true (para recordar la última opción arrancada con GRUB_DEFAULT=saved) y GRUB_ENABLE_CRYPTODISK=y (soporte de discos cifrados).
- **[term]** `CHS (Cylinders, Heads, Sectors) y LBA` (pág. 80): El PDF explica la limitación de 1024 cilindros (528 MB) del BIOS original de IBM con direccionamiento CHS frente a LBA, explicando por qué históricamente la partición /boot debía estar al inicio del disco (tamaño recomendado: 300 MB).
- **[path]** `/boot/grub/i386-pc/, /boot/grub/locale/, /boot/grub/fonts/` (pág. 81, 90): Estructura de subdirectorios de /boot/grub donde se alojan módulos (.mod), traducciones y fuentes gráficas.

## 3. Qué se ha puesto de más en la Web / Contenido Autor (5 ítems)
