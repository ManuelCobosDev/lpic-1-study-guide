## 2. Qué falta en la Web respecto al PDF Oficial (4 ítems)
- **[path]** `/proc/1/sched / /proc/<PID>/sched` (pág. 372): Archivo virtual del kernel donde consultar la prioridad estática (grep ^prio /proc/1/sched -> prio : 120) que ilustra la escala interna del kernel (100 a 139 para procesos normales, 0 a 99 para tiempo real).
- **[flag]** `ps --sort=-pcpu / --sort=pcpu` (pág. 373, 377): Opción de ordenación de ps por consumo de CPU ilustrada en el ejemplo de teoría (ps -e -o ... --sort=-pcpu) y requerida en el Ejercicio Exploratorio 1.
- **[term]** `Escala de prioridad estática (100 a 139) y desfase PRI en ps` (pág. 371, 372): Explicación del origen histórico del valor PRI en ps (escala de -40 a 99; la prioridad real del kernel se obtiene sumando 40, ej: PRI 80 + 40 = 120).
- **[command]** `schedtool` (pág. 377): Utilidad avanzada para inspeccionar y alterar parámetros de programación de CPU citada en el Ejercicio Exploratorio 2.

## 3. Qué se ha puesto de más en la Web / Contenido Autor (3 ítems)
- **[path]** `/etc/security/limits.conf`: Configuración de la directiva 'nice' en límites PAM por usuario o grupo para autorizar prioridades negativas sin root (Slide 10).
- **[term]** `Indicadores STAT en ps aux ('<' y 'N')`: Claves de examen para identificar procesos con nice negativo (alta prioridad '<') y nice positivo (baja prioridad 'N') en ps aux.
- **[command]** `pgrep / killall / sleep`: Comandos auxiliares implementados en las 4 misiones prácticas del laboratorio interactivo.
