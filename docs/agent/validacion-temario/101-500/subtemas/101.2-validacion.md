## 2. Qué falta en la Web respecto al PDF Oficial (5 ítems)
- **[flag]** `dmesg -H / --human` (pág. 41, 44): Opción de dmesg para paginar automáticamente la salida eliminando la necesidad de entubar con less (preguntada en el Ejercicio Exploratorio 3).
- **[flag]** `dmesg --clear` (pág. 37): Opción para limpiar el búfer circular del kernel ring buffer mencionada en la teoría.
- **[flag]** `journalctl --directory` (pág. 39, 44): Sinónimo en formato largo de -D para consultar registros de systemd en un directorio alternativo/montaje externo.
- **[flag]** `journalctl --boot=N` (pág. 38): Sinónimo en formato largo de -b N (--boot=0 para actual, --boot=-1 para previo).
- **[path]** `/etc/fstab` (pág. 36): Mencionado en la secuencia de inicialización como el archivo que consulta el kernel para montar los sistemas de archivos antes de ejecutar init.

## 3. Qué se ha puesto de más en la Web / Contenido Autor (5 ítems)
- **[command]** `update-initramfs / dracut / mkinitrd`: Comandos de generación y actualización del initramfs por distribución (muy útiles para el examen práctico).
- **[command]** `update-grub / grub-mkconfig`: Comandos de compilación de la configuración de GRUB tras editar /etc/default/grub.
- **[command]** `systemctl`: Gestión moderna de servicios bajo systemd y targets (multi-user.target, graphical.target).
- **[flag]** `dmesg -T / -w / --level`: Opciones prácticas de dmesg añadidas para diagnóstico en tiempo real y filtrado de severidad.
- **[flag]** `journalctl -u / -p / -f / --since`: Opciones avanzadas añadidas para filtrado de servicios y diagnóstico de incidencias.
