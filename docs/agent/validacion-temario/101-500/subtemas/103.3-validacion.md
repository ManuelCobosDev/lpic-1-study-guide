## 2. Qué falta en la Web respecto al PDF Oficial (5 ítems)
- **[command]** `gunzip` (pág. 276): Mencionado en el PDF oficial para descomprimir archivos gzip; la web enseña 'tar -z' y 'gzip' pero no cita el binario 'gunzip' explícitamente.
- **[command]** `bunzip2` (pág. 276): Mencionado en el PDF oficial para descomprimir archivos bzip2; la web enseña 'tar -j' y 'bzip2' pero no cita el binario 'bunzip2' explícitamente.
- **[flag]** `-empty` (pág. 271): Criterio de búsqueda en 'find' para localizar archivos o directorios vacíos ('find . -empty').
- **[flag]** `-not` (pág. 270): Operador de negación en 'find' para excluir coincidencias.
- **[flag]** `-print` (pág. 271): Acción por defecto en 'find', utilizada en el PDF junto a -exec para imprimir rutas coincidentes.

## 3. Qué se ha puesto de más en la Web / Contenido Autor (2 ítems)
- **[command]** `tar -J / xz`: Soporte moderno para compresión LZMA2 (.tar.xz), estándar actual de la industria y presente en preguntas modernas de LPIC-1.
- **[concept]** `Estructura interna del MBR`: Desglose sectorial detallado del Master Boot Record (446B bootloader + 64B particiones + 2B magic 0x55AA) respaldado con 'dd bs=512 count=1'.
