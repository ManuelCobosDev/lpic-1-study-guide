## 2. Qué falta en la Web respecto al PDF Oficial (6 ítems)
- **[path]** `/etc/screenrc y ~/.screenrc` (pág. 345): Archivos de configuración global y de usuario para GNU Screen documentados en la Lección 2 del manual oficial.
- **[path]** `/etc/tmux.conf y ~/.tmux.conf` (pág. 353): Archivos de configuración global y de usuario para tmux documentados en la Lección 2 del manual oficial.
- **[path]** `~/.toprc` (pág. 325): Archivo de configuración personal de top generado al guardar el orden interactivo con la tecla 'W'.
- **[flag]** `ps -o <columnas>` (pág. 329): Opción -o de ps para personalizar el formato y selección de columnas a mostrar (ej: ps -o pid,comm,%cpu,%mem) evaluada en ejercicios exploratorios.
- **[flag]** `screen -d -r / -D -R` (pág. 344): Modos combinados de desacople remoto y reanudación forzada en GNU Screen para recuperar sesiones activas.
- **[term]** `Modo Scrollback / Copia` (pág. 345, 353): Navegación histórica en el buffer de terminal para Screen (Ctrl+A [) y tmux (Ctrl+B [).

## 3. Qué se ha puesto de más en la Web / Contenido Autor (4 ítems)
- **[tool]** `disown -h [%n]`: Utilidad de bash para desvincular un job en caliente de la shell si se olvidó ejecutarlo preventivamente con nohup.
- **[tool]** `pidof`: Herramienta complementaria para consultar el PID de binarios directos en scripts.
- **[tool]** `pstree -p`: Utilidad visual para inspeccionar la jerarquía arbórea de procesos padre e hijos en el laboratorio.
- **[diagram]** `Diagramas de flujo fork()/exec() y Triángulo de Job Control`: Visualizaciones pedagógicas avanzadas en HTML/CSS integradas en diapositivas 2 y 3 para reforzar la comprensión técnica.
