## 2. Qué falta en la Web respecto al PDF Oficial (6 ítems)
- **[variable]** `$DISPLAY` (pág. 14, 28): Variable de entorno estándar para entornos gráficos/X11 (e.g. 'reptilium:0:2') explicada en el PDF y evaluada en los ejercicios de identificación de entorno.
- **[variable]** `$SSH_CONNECTION` (pág. 14, 20): Variable generada automáticamente por sshd para identificar los extremos de la conexión remota, ilustrada en el manual como ejemplo de variable de sesión.
- **[variable]** `$OSTYPE` (pág. 30, 36): Variable interna de Bash que reporta el sistema operativo subyacente, empleada en el ejercicio exploratorio 2 para scripts adaptativos.
- **[flag]** `export -p / export -n` (pág. 17): Opciones de export: '-p' para imprimir variables exportadas en formato reutilizable para scripts y '-n' para desmarcar una variable del entorno global manteniéndola como local.
- **[command]** `readonly` (pág. 18, 29): Comando incorporado de Bash para convertir variables en solo lectura (marcado como objetivo en el ejercicio guiado 'Haz que sea sólo de lectura').
- **[flag]** `set -o noclobber / set +o noclobber` (pág. 16): Opción de shell para evitar la sobreescritura accidental de ficheros existentes con el redireccionador '>', y su bypass con '>|'.

## 3. Qué se ha puesto de más en la Web / Contenido Autor (5 ítems)
- **[command]** `shopt login_shell`: Comprobación canónica y fiable en Bash moderno para verificar si el shell actual opera en modo login.
- **[command]** `sudo -i / sudo -s`: Comparativa práctica esencial en administración Linux entre shell de login simulado (-i) y shell no-login como root (-s).
- **[command]** `env -i`: Ejecución de procesos y subshells en entorno aislado sin herencia de variables de usuario.
- **[parameter]** `HISTCONTROL=erasedups`: Valor extendido para eliminar duplicados históricos en toda la sesión, complementando ignoredups e ignorespace del temario base.
- **[command]** `useradd -m -s /bin/bash`: Flujo de trabajo real para aprovisionar usuarios y demostrar la copia física de dotfiles desde /etc/skel.
