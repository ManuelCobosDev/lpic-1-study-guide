## 2. Qué falta en la Web respecto al PDF Oficial (6 ítems)
- **[flag]** `-c` (pág. 229): Opción de 'at -c <jobid>' para imprimir los comandos de la tarea a la salida estándar, evaluada frecuentemente en LPIC-1.
- **[flag]** `-v` (pág. 229): Opción de 'at -v' para mostrar la hora de ejecución programada antes de leer la tarea.
- **[flag]** `--all` (pág. 218): Opción 'systemctl list-timers --all' para listar temporizadores inactivos además de los activos.
- **[flag]** `--user` (pág. 232): Parámetro '--user' de systemd-run y journalctl para temporizadores gestionados por usuarios sin privilegios root.
- **[path]** `timers.target` (pág. 218): Directiva 'WantedBy=timers.target' en la sección [Install] de unidades .timer para su activación automática.
- **[command]** `mail` (pág. 222): Comando 'mail' para consultar las notificaciones enviadas a los buzones locales por cron y at.

## 3. Qué se ha puesto de más en la Web / Contenido Autor (4 ítems)
