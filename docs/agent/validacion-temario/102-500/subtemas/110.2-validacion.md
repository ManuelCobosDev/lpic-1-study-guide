- **[partial_list]** `/etc/init.d/` (pág. 538, 546): Directorio de scripts de inicio SysV citado en los objetivos oficiales para arranque y parada manual de servicios.
- **[command]** `chage` (pág. 541, 551): Comando oficial para consultar y modificar el envejecimiento y caducidad de contraseñas de usuario (flags -l para listar, -E para fecha de expiración, -M, -m, -W).
- **[command]** `usermod` (pág. 541-542): Uso para bloqueo (-L) y desbloqueo (-U) de cuentas, así como asignación de shells restrictivas (-s /sbin/nologin o /bin/false).
- **[command]** `passwd` (pág. 541, 551): Uso de flags -l (lock) y -u (unlock) para inhabilitar contraseñas anteponiendo '!' en /etc/shadow.
- **[command]** `update-rc.d / chkconfig` (pág. 546, 551-552): Herramientas clásicas en Debian y Red Hat para habilitar o deshabilitar permanentemente servicios en runlevels de arranque.
- **[command]** `lsof` (pág. 547): Utilidad para auditar puertos y conexiones de red abiertas mediante 'lsof -i'.
- **[command]** `nc / netcat` (pág. 550, 554): Herramienta empleada en los ejercicios prácticos para verificar puertos abiertos y servicios gestionados por xinetd (ej. servicio daytime).
- **[flag]** `netstat / ss -ltu, -l, -p, -t, -u` (pág. 547, 551): Opciones esenciales para listar sockets TCP y UDP en estado LISTEN y ver PIDs de procesos asociados.
- **[flag]** `systemctl disable --now` (pág. 546): Combinación recomendada de systemd para deshabilitar del arranque y detener inmediatamente un servicio.
- **[path]** `/sbin/nologin` (pág. 542, 551): Shell de bloqueo que rechaza el acceso de sesión imprimiendo un mensaje informativo configurable.
- **[path]** `/lib/x86_64-linux-gnu/libwrap.so.0` (pág. 547-548): Biblioteca compartida de TCP Wrappers inspeccionada con ldd para comprobar si un binario (ej. sshd) soporta hosts.allow/hosts.deny.
- **[path]** `/etc/services` (pág. 544, 545): Archivo de mapeo de nombres de servicios a puertos/protocolos TCP/UDP utilizado por xinetd e inetd.
- **[theory]** `Orden de evaluación en TCP Wrappers` (pág. 548): Regla estricta de evaluación: 1º /etc/hosts.allow (coincidencia = PERMITE); 2º /etc/hosts.deny (coincidencia = DENIEGA); 3º Si no coincide en ninguno = PERMITE por defecto.
- **[theory]** `Sintaxis y comodines de hosts.allow / hosts.deny` (pág. 548): Formato 'daemons : clients [: options]', comodines ALL, LOCAL, UNKNOWN, KNOWN, PARANOID y operador EXCEPT.
- **[theory]** `Directivas clave de configuración de xinetd` (pág. 543-544): Parámetros obligatorios en /etc/xinetd.d/: service, disable, socket_type, protocol, wait, user, server, server_args, only_from, no_access.
- **[theory]** `Unidades systemd.socket y directivas ListenStream / Accept` (pág. 545): Mecanismo de activación por socket nativo de systemd equivalente a xinetd, vinculación con unidades .service homónimas.
- **[exercise]** `4 Ejercicios Guiados oficiales` (pág. 549): Desbloqueo de cuentas, fijación de expiración a 'nunca' con chage -E -1, desactivación y verificación de CUPS con systemctl/ss, e inspección de libwrap con ldd.
- **[exercise]** `6 Ejercicios de Exploración oficiales` (pág. 550): Comportamiento de /etc/nologin con root y SSH keys, permisos de /etc/passwd vs /etc/shadow, y prueba del servicio daytime bajo xinetd.
