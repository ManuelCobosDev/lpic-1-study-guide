## 2. Qué falta en la Web respecto al PDF Oficial (8 ítems)
- **[command]** `exec` (pág. 100): Comando oficial del objetivo LPI 105.2. Sustituye el proceso del shell actual por el comando invocado y propaga su código de salida, evitando crear un subshell hijo.
- **[command]** `source / .` (pág. 100): Mecanismo para ejecutar un script en el contexto del shell actual en lugar de generar un proceso hijo, permitiendo que variables y funciones persistan en la sesión.
- **[command]** `printf` (pág. 106): Utilidad de formateo de salida con especificadores de tipo (%s, %d, saltos de línea \n) presentada en el manual como alternativa más robusta y portable frente a echo.
- **[flags_test_file]** `-ef, -ot, -L/-h, -u, -g, -k, -s, -N, -O, -G` (pág. 115): Operadores de prueba de archivos de test / [: -ef (mismo dispositivo e inodo/hard link), -ot (más antiguo que), -L (enlace simbólico), -u (SUID), -g (SGID), -k (sticky bit), -s (tamaño > 0).
- **[flags_test_string]** `-z, -n, =, !=` (pág. 117): Operadores para cadenas de texto en test / [: -z evalúa longitud cero, -n evalúa longitud mayor que cero, '=' y '!=' comparan igualdad lexicográfica.
- **[feature]** `shopt -s / -u nocasematch` (pág. 118): Control de la sensibilidad a mayúsculas y minúsculas en patrones de estructuras case dentro de Bash.
- **[concept]** `Arreglos (Arrays) en Bash` (pág. 103): Creación e indexación de listas tipo array ARRAY=(val1 val2), expansión ${ARRAY[@]}, longitud ${#ARRAY[@]} e inicialización a partir de argumentos ARRAY=("$@").
- **[variable]** `IFS (Input Field Separator)` (pág. 103): Variable interna que define los delimitadores de campos; el manual ilustra su preservación y modificación temporal (OLDIFS="$IFS"; IFS=$'\n') para iterar líneas de texto.
