## 2. Qué falta en la Web respecto al PDF Oficial (14 ítems)
- **[command]** `sendmail -bp` (pág. 365, 369): Comando oficial de emulación de Sendmail para examinar la cola de mensajes pendientes/no entregados (equivalente funcional directo a mailq, evaluado en el ejercicio guiado 2).
- **[command]** `sendmail -bi / sendmail -I` (pág. 362, 370): Opciones de Sendmail para regenerar e inicializar la base de datos binaria de alias (/etc/aliases.db), alternativas canónicas directas a newaliases (evaluadas en el ejercicio exploratorio 3).
- **[command]** `sendmail -q` (pág. 365): Comando de Sendmail para forzar el procesamiento inmediato de los mensajes en cola.
- **[keystroke]** `Ctrl + D (EOF)` (pág. 359, 369): Combinación de teclas obligatoria para cerrar el modo de entrada/redacción interactiva en el comando mail y despachar el correo (evaluado en el ejercicio guiado 1).
- **[command_syntax]** `uname -a | mail -a logs.tar.gz emma@lab1.campus` (pág. 360, 370): Uso de tuberías estándar y la opción '-a' de mailx para enviar la salida de un comando como cuerpo de correo junto con archivos adjuntos binarios (evaluado en el ejercicio exploratorio 1).
- **[path]** `/etc/aliases.db` (pág. 362): Fichero de base de datos indexada Berkeley DB que el demonio MTA consulta efectivamente en disco tras ser generado por newaliases.
- **[path]** `/dev/null` (pág. 363, 370): Dispositivo de descarte utilizado en /etc/aliases (e.g. 'test: /dev/null') para descartar automáticamente correos de pruebas sin saturar buzones (ejercicio exploratorio 2).
- **[path]** `/var/mail/ y /var/spool/mail/` (pág. 357): Rutas canónicas de los buzones de usuario en formato mbox en sistemas Linux/Unix.
- **[path]** `/var/spool/mqueue/ y /var/spool/postfix/` (pág. 365): Directorios del sistema de ficheros donde residen las colas de mensajes salientes de Sendmail y Postfix respectivamente.
- **[path]** `/etc/smrsh/` (pág. 363): Directorio de la shell restringida de Sendmail (Sendmail Restricted Shell) para limitar de forma segura qué comandos externos pueden ser ejecutados desde /etc/aliases mediante pipes '|'.
- **[syntax_rule]** `\usuario en ~/.forward` (pág. 364): Regla de escape con barra invertida para evitar bucles de reenvío infinito, asegurando que se deposite una copia en el buzón local mientras se envía copia a otra dirección.
- **[security_permission]** `Permisos estrictos de ~/.forward` (pág. 364): Requisito de seguridad donde el MTA ignora el fichero ~/.forward si tiene permisos de escritura para grupo u otros (debe pertenecer al usuario y tener permisos 600 o 644).
- **[protocol_commands]** `Comandos SMTP interactivos: HELO/EHLO, MAIL FROM, RCPT TO, DATA, QUIT` (pág. 358): Secuencia de diálogo interactivo SMTP vía netcat (nc localhost 25) y códigos numéricos de respuesta del servidor (220, 250, 354, 221).
- **[exercise_bank]** `Ejercicios guiados y exploratorios oficiales (páginas 366-370)` (pág. 366-370): Total ausencia en la web de los 3 ejercicios guiados y 3 exploratorios del manual LPI con sus respuestas oficiales detalladas.
