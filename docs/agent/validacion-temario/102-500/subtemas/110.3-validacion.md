## 2. Qué falta en la Web respecto al PDF Oficial (22 ítems)
- **[command_flag]** `ssh -p / -i / -l / -v / -vv / -vvv` (pág. 557-558, 569): Opciones operativas y de diagnóstico del cliente SSH: especificación de puerto alternativo (-p), selección explícita del archivo de identidad/clave privada (-i), usuario de conexión (-l) y niveles de depuración verbose (-v, -vv, -vvv) indispensables para diagnosticar fallos de negociación de algoritmos o rechazo de claves.
- **[command_flag]** `ssh-keygen -t / -b / -f / -N / -p / -l / -y` (pág. 558-560, 569): Generador de claves criptográficas: selección de algoritmo (-t rsa, dsa, ecdsa, ed25519), tamaño en bits (-b 2048/4096), archivo de destino (-f), asignación de contraseña (-N), cambio de passphrase de una clave existente (-p), cálculo de huella (-l) y obtención de clave pública a partir de la privada (-y).
- **[command_flag]** `ssh-agent y variables SSH_AUTH_SOCK / SSH_AGENT_PID` (pág. 562-563, 569): Mecanismo del agente de autenticación en memoria para evitar reingresar la contraseña: inicio interactivo ('ssh-agent /bin/bash') o exportación de variables de entorno mediante 'eval $(ssh-agent)' o 'eval $(ssh-agent -s)', y terminación del proceso con 'ssh-agent -k'.
- **[command_flag]** `ssh-add -l / -L / -d / -D / -t` (pág. 563, 569): Gestión de identidades cargadas en ssh-agent: listar huellas (-l), listar claves públicas completas (-L), borrar una clave concreta (-d), purgar todas las claves en memoria (-D) y definir tiempo de expiración de la clave cargada (-t).
- **[command]** `ssh-copy-id` (pág. 561, 571): Script para aprovisionar automáticamente claves públicas en ~/.ssh/authorized_keys del host remoto asegurando permisos restrictivos adecuados de directorio y archivo.
- **[command_flag]** `ssh -L (Reenvío local) con opciones -N y -f` (pág. 564-565, 570-571): Configuración de túneles locales (ssh -L [bind_address:]puerto_local:host_destino:puerto_remoto user@servidor_ssh), junto con -N (no ejecutar comandos remotos) y -f (bifurcar a segundo plano tras autenticar), permitiendo sortear firewalls hacia servicios remotos.
- **[command_flag]** `ssh -R (Reenvío remoto / reverso)` (pág. 566, 570): Configuración de túneles remotos (ssh -R [bind_address:]puerto_remoto:host_destino:puerto_local user@servidor_ssh) para exponer servicios internos locales a clientes conectados al servidor remoto.
- **[command_flag]** `ssh -X y -Y (Reenvío de interfaz gráfica X11)` (pág. 567-568, 570): Túneles para aplicaciones del sistema de ventanas X Window System: modo no confiable untrusted (-X) con restricciones de seguridad de la extensión Security y modo de total confianza trusted (-Y), vinculados a la variable DISPLAY y a la directiva 'X11Forwarding yes' en /etc/ssh/sshd_config.
- **[path_syntax]** `~/.ssh/ (id_rsa, id_dsa, id_ecdsa, id_ed25519 y .pub)` (pág. 558-561, 569): Estructura del directorio de usuario ~/.ssh/ (permisos obligatorios drwx------ / 700), pares de claves asimétricas de usuario (clave privada 600 / -rw------- y clave pública 644 / -rw-r--r--) y su convención de nomenclatura oficial.
- **[path_syntax]** `~/.ssh/authorized_keys y ~/.ssh/known_hosts` (pág. 560-562, 569): Archivos de control de acceso y confianza: authorized_keys (permisos 600) que contiene las claves públicas con permiso de acceso, y known_hosts que almacena las huellas de claves de host validadas para evitar ataques Man-in-the-Middle.
- **[path_syntax]** `/etc/ssh/ssh_host_* y /etc/ssh/sshd_config` (pág. 556-557, 571): Claves de servidor del sistema (/etc/ssh/ssh_host_{rsa,dsa,ecdsa,ed25519}_key y .pub) generadas en la instalación del demonio sshd, y directivas de endurecimiento en sshd_config como PermitRootLogin y AllowUsers.
- **[command_flag]** `gpg --gen-key y gpg --full-generate-key` (pág. 573-575, 587): Generación de pares de claves OpenPGP: asistente simplificado (--gen-key) vs configuración completa detallada (--full-generate-key) para seleccionar algoritmos (RSA, DSA, ECDSA, Ed25519), longitudes de bits (1024-4096) y fechas de expiración.
- **[command_flag]** `gpg --gen-revoke` (pág. 576-577, 587): Creación preventiva de certificados de revocación (revocation_file.asc) y su papel para invalidar claves públicas comprometidas o claves privadas extraviadas en los servidores de claves.
- **[command_flag]** `gpg --list-keys (-k) / --list-secret-keys (-K) / --fingerprint` (pág. 577-578, 587): Inspección de llaveros locales: listado de claves públicas (-k) y privadas (-K), estructura de cabeceras (pub, uid, sub) y visualización de la huella digital criptográfica (--fingerprint) para verificar autenticidad.
- **[command_flag]** `gpg --edit-key (trust, sign)` (pág. 579-581, 587): Modificación interactiva de parámetros de clave en la Red de Confianza (Web of Trust): asignación de niveles de confianza ('trust': desconocido, no confío, marginal, total, absoluta) y firma mutua de claves ('sign') para avalar identidades.
- **[command_flag]** `gpg --export / --export-secret-keys / --armor (-a) / --output (-o)` (pág. 581-582, 587-588): Exportación de material criptográfico: exportación de clave pública binaria o con armadura ASCII (-a / --armor) para envío por correo o web, exportación de clave privada (--export-secret-keys) y redirección a fichero (--output / -o).
- **[command_flag]** `gpg --import y gpg --keyserver (--send-keys / --recv-keys)` (pág. 582-583, 587): Importación de claves locales (--import) y sincronización con servidores de claves públicos (HKP/HTTP) para publicar claves (--send-keys) o descargar claves de terceros mediante su Key-ID (--recv-keys).
- **[command_flag]** `gpg --encrypt (-e) y --recipient (-r)` (pág. 583-584, 588): Cifrado asimétrico de archivos mediante la clave pública del destinatario: uso combinado de -e / --encrypt con -r / --recipient <uid> para producir ficheros cifrados .gpg (o .asc con armadura ASCII).
- **[command_flag]** `gpg --decrypt (-d)` (pág. 584-585, 588): Descifrado asimétrico utilizando la clave privada del usuario receptor y su contraseña correspondiente (gestionada por gpg-agent y pinentry), con volcado a salida estándar o archivo con -o.
- **[command_flag]** `gpg --sign (-s) / --clearsign / --detach-sign (-b) / --verify` (pág. 585-587, 588): Mecanismos de firma digital con GPG: firma binaria comprimida (--sign / -s), firma legible en texto claro (--clearsign entre cabeceras PGP), firma separada (--detach-sign / -b generando archivo .sig) y verificación de autenticidad e integridad (--verify).
- **[path_syntax]** `~/.gnupg/ (pubring.kbx, trustdb.gpg, openpgp-revocs.d/)` (pág. 573, 587): Estructura del directorio ~/.gnupg/ (permisos drwx------ / 700), archivo keybox 'pubring.kbx' de GnuPG 2.1+, base de datos de confianza 'trustdb.gpg', y directorio 'openpgp-revocs.d/' para certificados de revocación automáticos.
- **[exercise]** `50 Ejercicios Guiados y 20 de Exploración del manual LPI 102-500` (pág. 569-571, 587-589): Ausencia de los ejercicios oficiales del PDF: configuración y conexión con sonya/halof, purga de known_hosts, secuenciación de ssh-agent con ssh-add, sintaxis de túneles dobles en un comando (-L 8080:... -L 8585:...), tablas de opciones cortas/largas de gpg y pasos de revocación de clave pública.
