## 2. Qué falta en la Web respecto al PDF Oficial (13 ítems)
- **[flag]** `hostnamectl --static / --transient / --pretty` (pág. 427, 432, 435): Modificadores para consultar y configurar independientemente los tres tipos de hostname en systemd: estático (/etc/hostname), transitorio (kernel/DHCP) y pretty (descripción UTF-8 libre para interfaces gráficas).
- **[command]** `nmcli device wifi rescan` (pág. 441, 445, 448): Subcomando necesario para forzar a NetworkManager a reescanear inmediatamente los puntos de acceso Wi-Fi disponibles (objeto de pregunta en el Ejercicio de Exploración 2).
- **[command]** `nmcli radio wifi on / off` (pág. 441, 444, 447): Subcomando de gestión de estado de radio para activar o desactivar la interfaz inalámbrica por software (objeto de pregunta en el Ejercicio Guiado 3).
- **[command]** `nmcli connection delete <nombre>` (pág. 442, 445, 448): Subcomando para eliminar perfiles de conexión guardados en NetworkManager (objeto de pregunta en el Ejercicio de Exploración 1).
- **[command]** `wpa_passphrase` (pág. 443, 445, 448): Utilidad oficial para generar bloques de configuración con PSK cifrada en 256 bits a partir de SSID y contraseña para /etc/wpa_supplicant/ (objeto de pregunta en el Ejercicio de Exploración 4).
- **[path]** `/etc/systemd/network/` (pág. 443, 444, 447): Directorio de administración local prioritario para ubicar los archivos de configuración .network personalizados de systemd-networkd.
- **[path]** `/run/systemd/network/ y /lib/systemd/network/` (pág. 443): Jerarquía de directorios de systemd-networkd donde /etc sobreescribe a /run (en tiempo de ejecución) y a /lib (distribución/paquetes).
- **[path]** `/etc/wpa_supplicant/wpa_supplicant-*.conf` (pág. 443): Ruta y convención de nombres para la configuración de wpa_supplicant vinculada a una interfaz específica mediante plantillas de systemd wpa_supplicant@<interfaz>.service.
- **[term]** `Portal (conectividad de nmcli)` (pág. 440, 444, 447): Estado de conectividad reportado por 'nmcli general status' que indica que el acceso a Internet está bloqueado por un portal cautivo web (Ejercicio Guiado 1).
- **[term]** `Name Service Switch (NSS) y bases de datos` (pág. 429): Mecanismo central de glibc gobernado por /etc/nsswitch.conf para determinar el orden de búsqueda y fuentes de resolución para nombres de host ('hosts: files dns').
- **[term]** `Secciones [Match] y [Network] de systemd-networkd` (pág. 443, 445, 448): Estructura INI declarativa de los ficheros .network, incluyendo la coincidencia por comodines 'Name=en*' para interfaces ethernet (Ejercicio de Exploración 3).
- **[exercise]** `8 Ejercicios Guiados Oficiales (Manual LPI)` (pág. 431, 434, 444, 447): Cuestiones prácticas sobre listar adaptadores, nomenclatura wlo1, rol de /etc/network/interfaces con DHCP, estado Portal en nmcli, conexión CLI Wi-Fi con contraseña, nmcli radio wifi y ruta de configuración en systemd-networkd.
- **[exercise]** `8 Ejercicios de Exploración Oficiales (Manual LPI)` (pág. 432, 435, 445, 448): Preguntas avanzadas sobre hostnamectl --static, chasis/icono en hostnamectl, sintaxis múltiple de /etc/hosts, nameserver único en /etc/resolv.conf, nmcli connection delete, nmcli device wifi rescan, Name=en* en [Match] y uso de wpa_passphrase.
